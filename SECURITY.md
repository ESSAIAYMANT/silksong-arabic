# Security

The current source preview is not a security-certified or signed product. Please report reproducible installer defects through GitHub issues with redacted, minimal details. Do not post exploitable secrets, personal information or full game files. For a potentially sensitive vulnerability, open an issue requesting a private contact channel without disclosing exploit details publicly.

Do not disable operating-system protections to test unsigned releases. Test in an isolated directory with synthetic fixtures. The real-payload test is local-only and must never be uploaded because it copies game binaries.
