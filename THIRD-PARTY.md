## Game-dependent inputs

The plugin uses compile-time references from the user's legally owned Silksong installation (Unity, Assembly-CSharp and TeamCherry assemblies). They are not uploaded here. Local compatibility hashes in `evidence/RC3-PACKAGE-MANIFEST.xml` are fingerprints, not the underlying files.

The local `arabicfont.bundle` was generated by replacing font data in a game font-bundle template and retaining material/texture objects. That is not established as an independently sourced asset. It and all compiled payloads containing it are excluded from this publication. A standalone independently built font asset is a release/signing prerequisite.

Arabic translations refer to the game's copyrighted narrative and interface; game names, trademarks and underlying content remain with their owners. The project is unofficial and not endorsed by Team Cherry.
